# Decisiones (NE-0004)

Una decisión por archivo: `AAAA-MM-DD-tema.md` (p. ej. `2026-10-29-identidad-web.md`).
Así dos conversaciones que trabajan a la vez nunca toman el mismo número ni
chocan al escribir al final del mismo archivo. Las decisiones anteriores al 29
de octubre de 2026 siguen en `docs/DECISIONS.md` y se citan como siempre.

Plantilla:

```markdown
# Título corto de la decisión

**Fecha:** AAAA-MM-DD · **Frente:** <frente>

**Contexto.** Qué pasaba.

**Decisión.** Qué se decidió.

**Alternativa descartada.** Qué más se consideró y por qué no.
```
